

# 📊 Анализатор текста и частотности слов

Простой и понятный консольный скрипт на Python для базового анализа текста. Программа принимает текст от пользователя, очищает его от основных знаков препинания, приводит к нижнему регистру, а затем считает количество уникальных слов и выводит статистику их повторений.

## ✨ Возможности

* 🔄 **Нормализация текста:** автоматический перевод всех символов в нижний регистр.
* 🧹 **Очистка от пунктуации:** удаление базовых знаков препинания (`.`, `,`, `!`, `?`), чтобы они не влияли на подсчет слов.
* 🔢 **Подсчет уникальности:** выводит общее количество различных (уникальных) слов в тексте.
* 📈 **Анализ частотности:** показывает, сколько раз каждое слово встречается в введенном тексте.

## ⚙️ Требования

* Python 3.x
* Скрипт использует только встроенные библиотеки Python, поэтому установка дополнительных зависимостей не требуется.

## 🚀 Запуск и использование

1. Сохраните код в файл, например, `text_analyzer.py`.
2. Откройте терминал (командную строку) и перейдите в папку с файлом.
3. Запустите скрипт командой:
   ```bash
   python text_analyzer.py
   ```
4. Введите текст, когда программа попросит об этом, и нажмите `Enter`.

## 💡 Пример работы

**Ввод пользователя:**
```text
Введите текст: Привет, мир! Привет, Python. Python - это круто.
```

**Вывод программы:**
```text
Количество разных слов: 5
привет : 2
мир : 1
python : 2
это : 1
круто : 1
```

## 🛠 Как это работает (Алгоритм)

1. Считывается ввод пользователя с помощью `input()`.
2. Текст переводится в нижний регистр (`lower()`).
3. В цикле удаляются заданные знаки препинания (`replace()`).
4. Текст разбивается на список слов по пробелам (`split()`).
5. С помощью `set()` подсчитывается количество уникальных элементов.
6. С помощью словаря (`dict`) и цикла `for` подсчитывается частота каждого слова.

## 📌 Примечания и возможные улучшения

В текущей версии скрипт удаляет только 4 знака препинания: `.`, `,`, `!`, `?`. 
Если вы планируете расширить функционал, вот несколько идей для улучшения:

* **Расширение списка пунктуации:** Добавить удаление кавычек, тире, двоеточий и точек с запятой (или использовать модуль `string` и `string.punctuation`).
* **Оптимизация подсчета:** Заменить ручной подсчет через словарь на встроенный класс `Counter` из модуля `collections`.
* **Игнорирование предлогов:** Добавить фильтрацию коротких слов (предлогов и союзов), если требуется анализ только смысловых единиц.
